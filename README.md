# 📘 1. Introduction to Generative AI

Generative AI is a class of artificial intelligence that focuses on generating new data similar to the training data. Unlike traditional AI, which focuses on classification or prediction, generative AI creates new outputs.

## Key Characteristics:
- Learns from large datasets  
- Produces human-like outputs  
- Works across multiple domains  
- Enables creativity and automation  

## Domains of Generative AI:
- Text generation  
- Image generation  
- Audio and music generation  
- Video generation  
- Code generation  

---

# 🧠 2. Types of Generative AI Models

## 2.1 Generative Adversarial Networks (GANs)
GANs consist of two neural networks:
- Generator → Creates fake data  
- Discriminator → Evaluates authenticity  

### Applications:
- Image generation  
- Deepfakes  
- Style transfer  

---

## 2.2 Variational Autoencoders (VAEs)
VAEs encode input data into a latent space and decode it back.

### Features:
- Smooth latent space  
- Probabilistic modeling  
- Controlled generation  

---

## 2.3 Transformer Models
Transformers revolutionized AI by replacing sequential processing with attention mechanisms.

### Advantages:
- Parallel computation  
- Long-range dependency capture  
- Scalability  

---

## 2.4 Restricted Boltzmann Machines (RBMs)
RBMs are used for:
- Feature extraction  
- Pattern recognition  
- Dimensionality reduction

# 🔷 4. Transformer Architecture

## Key Components:

### 4.1 Self-Attention
- Identifies relationships between words  
- Improves contextual understanding  

### 4.2 Multi-Head Attention
- Captures multiple perspectives  
- Enhances learning capacity  

### 4.3 Positional Encoding
- Maintains sequence order  

### 4.4 Encoder-Decoder
- Encoder → Processes input  
- Decoder → Generates output  

---

# 🧩 5. Working of Transformers

1. Input text → Tokenization  
2. Tokens → Embeddings  
3. Add positional encoding  
4. Apply attention mechanism  
5. Pass through feedforward layers  
6. Generate output
